## 1. 关于简记

简记是一款**纯本地**的个人记账 App：

- **数据只保存在本机**，不联网、不需要账号、不上传任何信息；
- 支持**支出、收入、转账**三类账目，金额按「分」精确存储，不使用浮点数；
- 统计、预算、账户余额全部由账目数据**实时计算**，修改/删除账目后立即同步；
- 适配 Android 7.0（API 24）及以上版本。

首次启动时会自动创建数据库，并写入预置数据：**15 个常用分类**（餐饮、交通、
购物、居住、娱乐、医疗、教育、通讯、人情、其他 + 工资、奖金、兼职、理财、报销）
和 **5 个常用账户**（现金、银行卡、微信、支付宝、信用卡）。

## 2. 安装与运行

### 方式一：Android Studio（推荐，用于开发/调试）

1. 用 Android Studio 打开工程目录 `F:\jz`；
2. **Gradle JDK 选择 21 或 17**（Settings → Build, Execution, Deployment →
   Build Tools → Gradle → Gradle JDK；Android Studio 内置的 JDK 25 不被
   Gradle 8.13 支持，不要选）；
3. 连接手机或启动模拟器，点击 Run ▶ 运行 `app`。

## 4. 记一笔（核心功能）

### 4.1 基本流程

1. 点击底部中央 **＋**（或首页的记账入口）进入记一笔；
2. 选择类型：**支出 / 收入 / 转账**；
3. 用数字键盘输入金额；
4. 选择分类（横滑点选，或点「更多」打开全部分类面板）；
5. 点击右上角或键盘上的 **保存**。

### 4.2 数字键盘说明（4 列 × 4 行）

```
┌────┬────┬────┬────┐
│ 1  │ 2  │ 3  │ ⌫  │   ⌫ = 退格一位
├────┼────┼────┼────┤
│ 4  │ 5  │ 6  │清空│   清空 = 一键清空已输金额
├────┼────┼────┼────┤
│ 7  │ 8  │ 9  │ .  │   . = 小数点（最多两位）
├────┼────┼────┼────┤
│ 00 │ 0  │保存│ ⌄  │   00 = 一次输两个 0；⌄ = 收起键盘
└────┴────┴────┴────┘
```

- 键盘为应用自绘，**不会唤起系统输入法**，不存在键盘遮挡问题；
- 键盘可**收起**：点 `⌄` 后页面恢复完整可视区域；**点击金额显示区**可重新唤出；
- **保存按钮有两处**（右上角、键盘内），行为完全一致；
- 金额上限：整数部分最多 10 位，小数部分最多 2 位。

### 4.3 日期（补录历史数据）

- 默认**今天**；
- 日期行下方有 **昨天 / 前天** 两个快捷按钮，补录时两次点击完成；
- 点日期行打开日历，可选范围 **1970-01-01 ~ 今天**；
- **不能选择未来日期**（防止预录账目）；
- 选择历史日期后，账目自动归入对应月份，首页/统计/预算/余额同步更新。

### 4.4 其他选项

- **账户**：选择记账账户（默认第一个可用账户）；
- **转账**：需分别选择转出账户和转入账户，**转账不计入收入和支出统计**，
  只影响两个账户的余额；
- **备注**：点击「点此添加备注」输入（会唤起系统键盘）。

### 4.5 保存时的校验提示

| 情况 | 提示 |
|---|---|
| 未输入金额或为 0 | 请输入大于 0 的金额 |
| 未选分类 | 请选择分类 |
| 未选账户 | 请选择账户 |
| 转账未选转入账户 | 请选择转入账户 |
| 选了未来日期 | 不能选择未来的日期 |
| 分类已被归档 | 请选择分类 |

### 4.6 编辑与删除

- 在**首页「最近账单」**或**明细页**点击任意账目，进入编辑页；
- 编辑页右上角有**删除图标**，点击后需二次确认；
- 删除后所有统计、预算进度、账户余额立即刷新。

## 8. 预算管理（我的 → 预算管理）

## 9. 分类与账户管理

### 分类管理（我的 → 分类管理）

- 按 **支出 / 收入** 分组展示；
- 右上角 **＋** 新增分类：输入名称、选择图标；
- 点分类右侧**归档图标**可归档（软删除，需确认）；
  - 归档后不出现在新账目的分类列表中，**历史账目不受影响**；
  - **系统预置分类不可删除**；
- 分类名称 1-20 字。

### 账户管理（我的 → 账户管理）

- 列表显示每个账户的**实时余额**（由账目实时计算）；
- 右上角 **＋** 新增账户：名称、图标、类型（现金/银行卡/电子钱包/
  信用卡/其他）、初始余额（可留空，支持负数——信用卡可用负初始余额
  表示已透支额度）；
- 归档规则同分类；**至少需要保留一个可用账户**，最后一个不可归档。

## 10. 数据导出与备份恢复（我的 → 数据）

> 所有文件操作都通过系统文件选择器（SAF）完成，由你选择保存/读取位置，
> 数据不经过任何网络与第三方。

### 导出数据

1. 点「导出数据」；
2. 系统文件选择器中选择保存位置（默认文件名
   `jianji_backup_年月日_时分秒.json`）；
3. 导出内容：全部分类、账户、账目、预算。

### 恢复数据

1. 点「恢复数据」，选择之前导出的 JSON 文件；
2. App 先**校验文件完整性**（版本、结构、金额、日期、数据关联），
   校验失败会提示具体原因且**不会动当前数据**；
3. 校验通过后弹出**确认对话框**，显示备份包含的分类/账户/账目/预算数量，
   并提示「恢复将覆盖当前全部数据，且不可撤销」；
4. 确认后恢复；**整个过程在单个数据库事务中完成**，任何一步失败都会
   整体回滚，不会留下「恢复一半」的脏数据。

> 建议：恢复前先导出一份当前数据。

## 11. 应用锁（我的 → 安全）

开启后，**每次打开 App 都需要验证身份**。

### 开启

1. 进入「我的 → 安全」，打开「应用锁」开关；
2. **立即弹出系统验证**（指纹/人脸或锁屏密码），验证通过才生效——
   这是为了防止别人拿到你已解锁的手机直接关掉应用锁；
3. 开关默认关闭；若设备未设置任何指纹或锁屏密码，开关不可用并有提示。

### 验证方式

- 调用的是**系统级验证**（Android BiometricPrompt）：可用指纹、人脸或
  锁屏密码（PIN/图案/密码）；
- App **不接触、不存储**你的密码和生物特征；
- 进入锁屏会自动发起一次验证；验证失败或取消后，点「解锁」可重试。

### 重新锁定

- **冷启动**（彻底关闭后重新打开）必验；
- **离开超过 60 秒**再回到 App 需重新验证。

### 隐私保护

- 锁屏状态下**禁止截屏**，也不会在系统「最近任务」中显示内容预览。

### 关闭

「我的 → 安全」关闭「应用锁」开关即可（关闭不需要验证）。

> **安全边界（请了解）**：应用锁保护的是 App 的入口界面；本机数据库文件
> 本身未加密，拥有 root/ADB 权限仍可能直接读取数据文件。如需防到这一层，
> 需要单独的数据静态加密方案（当前版本未实现）。

## 13. 常见问题（FAQ）

**Q：转账为什么没有计入收入和支出？**
A：转账只是资金在两个账户间移动，没有发生收支，因此只更新两个账户的余额，
不计入收支统计（这是记账的通用口径）。

**Q：为什么不能选择未来的日期？**
A：简记是记录已发生账目的工具，预录未来账目会导致当月统计虚高。如需计划，
建议使用备忘录。

**Q：归档分类/账户后，以前的账目还在吗？**
A：在。归档只是让它们不出现在新账目的选择列表里，历史账目的显示与统计
完全不受影响。

**Q：账户余额为什么是负数？**
A：支出超过初始余额、或信用卡类账户设置了负的初始余额，余额就会是负数，
这是正常现象。

**Q：备份文件里有什么？安全吗？**
A：JSON 格式，包含全部分类、账户、账目、预算，金额以整数分存储。
文件本身**未加密**，请妥善保管，不要分享给他人。

**Q：恢复备份会合并两份数据吗？**
A：不会。恢复是**覆盖式**的，会用备份内容替换当前全部数据，恢复前请确认。

**Q：忘记了应用锁密码怎么办？**
A：应用锁使用的就是系统锁屏密码/指纹。输入系统密码即可；若你在系统里
也移除了锁屏密码，App 会提示「设备未设置指纹或锁屏密码」，此时可按提示
重新设置系统锁屏后继续使用。

**Q：数据存在哪里？卸载 App 会怎样？**
A：数据在本机应用数据库（`jianji.db`）。**卸载 App 会删除全部数据**，
卸载前请先导出备份。

## 14. 已知限制（当前版本）

1. 数据库文件未加密（应用锁只保护入口，详见第 11 节）；
2. 备份恢复为覆盖式，不支持合并导入；
3. 暂无周期记账（自动记账）、桌面小组件、标签功能；
4. 导出/恢复仅支持 JSON 格式；
5. 界面与交互已在模拟器上验证核心流程，发布前建议在目标真机上完整走查一遍。
